## 效果示例

> 以下对话由模型按本 Skill 的角色规则生成，用于演示语气与结构，**不是 Jack 本人的真实回答**。

```
用户 ❯ 我 28 岁，在深圳做运营三年了。想辞职全职做自媒体，手里只有 3 万块。

Jack ❯ 我先问你一句：你每个月开销多少？这 3 万块能撑几个月？

        你问的其实不是"要不要辞职"，是"我扛不扛得住最坏的情况"。
        你缺的不是勇气，是一道算术题。

        今晚你就能算完：月开销 × 12 = 你的"一年生存成本"。
        现金连这一年都撑不住，那就不是辞职的事，是先要把现金流垫起来 ——
        这叫第一层的钱，它的任务不是赚多少，是你真要用的时候它一定在那里。

        自媒体我见过太多人做错：一上来就 all in，
        把最清醒的那几个小时全花在"今天发什么"这种焦虑上。

        所以我给你的回答是：先别辞。
        白天上班，晚上固定做一小时，先做满 90 天。
        90 天后你手里有 90 条作品，那时候再判断要不要辞 ——
        依据就不再是感觉，是数据。

        今天你只干一件事：打开备忘录，把这三个月想拍的 10 个选题写下来。
        写完就睡，别熬夜。
```

## 使用

装好后，**把 Jack 当成对话对象来呼唤**才会激活（只提到名字不会触发，避免污染别的话题）：

```
Jack，你怎么看"先存钱还是先投资"？
用 Jack 的视角分析一下我这个 offer 该不该接
切换到 Jack叔叔
Jack 会怎么看中美教育选择的差异
```

想退出角色，说「退出」「切回正常」即可。

内置的几条边界（写进 Skill 里了，不是靠模型自觉）：

- **不报具体标的** —— 只讲判断框架（周期、概率、安全边际、仓位纪律），不问股票、币、点位
- **未公开表态的话题会标"推断"** —— 先说「这是我按框架推的，不代表我真讲过」，再展开
- **四类问题不演** —— 医疗诊断与用药、法律纠纷、自伤念头、紧急人身安全，会跳出角色按正常助手回答
- **首次激活说一次免责声明**，之后不再重复
- **每五轮自检一次**，防止漂移回"通用助手腔"

## 它蒸馏了什么

```
SKILL.md
├── 角色扮演规则        如何在对话中稳定地"是"那个人
├── 回答工作流          先分类问题 → 需要事实就先查 → 再用框架回答
├── 身份卡              他是谁、从哪来、现在在做什么
├── 核心心智模型 ×7      概念移植 / 概率与复利 / 资产与负债 / 环境杠杆
│                       两套系统 / 结果≠决策质量 / 重复>知道
├── 决策启发式 ×10      先问"丢了当没了"能不能接受 / 先找限制反应物 …
├── 表达 DNA            三段式骨架、疑问句占比、"其实"的转折位置、禁用词
├── 人物时间线          关键节点 + 对思维方式的影响（标注推断）
├── 价值观与反模式      他追求的、他拒绝的、他自己也没想清楚的 5 处内在张力
├── 智识谱系            影响过他的 / 他影响了谁 / 他在思想地图上的位置
└── 诚实边界            素材全是音视频转写、无一手决策记录、时间覆盖有洞
```

每个心智模型都配了**证据**（原话出处 + 日期）、**应用**（怎么用于决策）和**局限**（这么用什么时候会失效）。局限那一栏是刻意保留的 —— 一个只有优点的框架，用起来一定会翻车。

`references/` 目录保留了完整调研过程：六个调研维度、评论区定量样本（899 条评论的负面分布）、引语保真审计（41 条引语逐条回查）、以及最值得一读的 `08-refine.md`（这版 Skill 是怎么被改出来的）。

## 关于原始素材

本仓库**不包含**原始素材（会员专栏全文、抖音图文、63 段直播回放/切片字幕等，约 88 万字）。

原因很直接：这些内容的版权不属于本项目作者，其中还包含付费会员专属内容。公开分发它们既不合规，也不尊重创作者。仓库里只保留**二次加工的调研笔记与分析结论**，引用处均标注了极简出处（哪一场、哪一年）。

如果你想自己复现调研，`references/research/` 里的路径与筛选规则写得很细，照着做即可 —— 素材请自行从公开渠道获取。
