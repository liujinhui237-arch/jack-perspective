## ⑤ 环境注意事项（恢复时必读）

1. **子 agent 对 `<skills 目录>\` 没有写权限**——它们写到 `work\research\` 或 `<工作目录>\` 下，再由主会话搬运进 skill 目录。
2. **`spawn_agent` 的任务投递不可靠**：本轮的 `agent3b_expression` 两次报告"收件箱里没有任务"，`agent1b_writings` 长时间无产出。**01 与 03 最终由主 agent 自己写脚本完成**。后续如需并行，派发后必须验证 agent 是否真的拿到任务。
3. **代理陷阱**：本机 `HTTP_PROXY` / `HTTPS_PROXY` / `ALL_PROXY` 指向死端口 `127.0.0.1:9`，默认 HTTP 请求会失败；抓取脚本需显式绕过代理（`ProxyHandler({})`）。
4. **网络授权按轮次失效**，长时间抓取任务要分批续跑；脚本已做断点续传（已存在的文件会跳过）。
5. **登录态**：抓取 B 站与会员站素材需要本机登录态（以本地文件形式保存，不随本仓库分发）。抓取完成后建议退出登录使其失效。
